# Girl Scouts Dashboard

Interactive dashboard for Ariella and Valentina's 2026 Girl Scouts season in San Luis Obispo.

## Features

**Events tab** — All 19 SLO program events with:
- Level filter (All Eligible / Daisy Only / Next 30 Days)
- Countdown badges and low-spot alerts
- Level tags (Daisy / D+B / D+B+J / All Levels)

**Outdoors Challenge tab** — Love the Outdoors Challenge 2026:
- Per-daughter progress tracking for Ariella and Valentina
- 50 activities grouped by category (Nature, Active, Creative, Social, Science, Cooking, Outdoors)
- Progress bar with patch milestone at 25/50
- Checkboxes saved automatically in the browser

## Hosted

Deploy to GitHub Pages by enabling it in repo Settings > Pages (source: main branch, root folder).

## Data source

San Luis Obispo Girl Scouts program flyer and the Girl Scouts Love the Outdoors Challenge 2026.
